A beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.4.9-beta.zip` below.

## What's new since v0.4.8-beta

**The dust blows all around you, and stays outside.** In v0.4.8 the wind died a moment after the Guerrilla world loaded (Armageddon's levels set their wind from boxes placed in each level, and with none about it's 0), so the dust only had its first puff, left hanging where it was made: the flat band of haze some of you saw. Now the dust streams past you wherever you go, and fades away within moments when you walk under a roof or into a building, as in Guerrilla.

**Guerrilla's wind.** The wind now wanders as Guerrilla's does: every 20 seconds it picks a new speed within 40 mph of the last, inside each zone's 50 to 80 mph, and eases into it. The dust grows and thins with it.

**Options → Experimentals.** A new page in the game's Options menu, from the main menu or the pause menu, for RFA-Mod's own settings. For now it holds the Guerrilla world's switches: the sun's shadows and shafts, fog, blowing dust, Guerrilla's particles and tone mapping, colour correction, sky brightness and clock speed. Each changes as you pick it and is saved in `rfa_mods.ini`. The menu saves whole numbers, so fine values such as `Exposure=1.2` stay in the ini; a setting isn't touched unless you change it in the menu.

**Not there yet:** people, vehicles and plants; Guerrilla's missions and story; its far mountains up close; the minimap; effects' sounds, the gusts of dust along the ground and the dust devils, the dust thinning right beside a building, and the effects placed on their own around the map. Glass and effects aren't fogged. Some tall structures can stay hanging in the air while a thin support still holds them.

## The Guerrilla world

No need to build your world again: the world builder hasn't changed since v0.4.8-beta. If you're coming from an older version, build it again with this version's `editor\GuerrillaWorld.exe`.

## Trying the Guerrilla world for the first time

1. You need **Red Faction: Guerrilla Steam Edition** installed (the original, `Red Faction Guerrilla` in your Steam library; Re-MARS-tered's files aren't read yet), and about 1 GB free where RFA-Mod is.
2. In `rfa_mods.ini`, set `GuerrillaDir=` under `[Launcher]` (just below `GameDir=`) to Guerrilla's folder, for example `C:\Program Files (x86)\Steam\steamapps\common\Red Faction Guerrilla`. Both tools read it. (Or give the folder to each tool as its argument.)
3. Run `editor\GuerrillaWorld.exe` (a few minutes).
4. Run `editor\GuerrillaHud.exe` for Guerrilla's HUD (a few seconds). `editor\GuerrillaHud.exe --remove` takes it away again; remove it only that way, since one of its files also holds the pictures of Armageddon's own HUD.
5. Start the game with `RFAModLauncher.exe`, open the developer console with the ` key (from the main menu is fine) and type `level rfg_12_11`.

Run the tools again after updating RFA-Mod. To take the world away, remove the HUD first (`--remove`), then delete `rfg_*`, `zonescript_rfg.vpp_pc`, `rfg.gtodx`, `table.vpp_pc\territories.xtbl`, `effects.vpp_pc\vfx_containers.asm_pc` and `misc.vpp_pc\bitmaps_pc` from `overrides\build\pc\cache\`.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor and its tools: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.4.8-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini`. This version adds no new settings.

## Please note

- This is a beta, and the Guerrilla world a work in progress: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, a crash's `logs\crash-*.dmp` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
