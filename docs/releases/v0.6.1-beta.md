A beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.6.1-beta.zip` below.

## What's new since v0.6.0-beta

An update for the level editor only. The mods and the Guerrilla world are the same as in v0.6.0-beta.

**The editor shows the Guerrilla world's files.** Before, the explorer and search listed only the game's own archives, so nothing the Guerrilla builder had made showed up. Now:
- **Explorer → build\pc\cache → New files** lists what the builder made: Guerrilla's characters (Mason, the EDF, civilians), vehicles, guns, their rigs, sound banks, scripts and tables. Each mod's data under `mods\` is listed too (for example `mods\guerrilla_gear\animations`).
- **Search** finds them, and says where each one comes from ("new file", "the mod's data").
- **Previews** work on them as on the game's own: a character's rig in 3D, a vehicle inside its container, an animation, a gun's container.
- A new file that one of the game's archives also has is marked **unused**, since the game takes the archive's.
- **Saving** a change to one of these files writes it in place and keeps the copy from before, so **Restore** gives it back.
- If you run the Guerrilla builder while the editor is open, the explorer and search are made again when you come back to the editor.

`docs\editor-guide.md` has the details.

## Updating

**From v0.6.0-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini`. Your Guerrilla world doesn't need building again.

**From anything older:** follow the v0.6.0-beta notes: after copying the files, build the Guerrilla world again (`editor\GuerrillaBuilder.exe`, then **Build**; the launcher tells you).

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**.
- Windows 10 or 11.
- For the editor and the builder: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Please note

- This is a beta: please report problems as an issue here. `logs\rfa_mods.log`, the editor's `logs\editor.log` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
