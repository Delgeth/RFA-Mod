A beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.4.6-beta.zip` below.

## What's new since v0.4.5-beta

**Guerrilla's effects play in the Guerrilla world.** Every effect its objects use is converted from your copy of Guerrilla, with its textures: the fires burning in barrels, the glow of the EDF screens and the barricade lights, the tag icons, and what a prop shows when it breaks (the smoke and splinters of a crate, the sparks of a generator, the dust of a toolbox). Sounds aren't there yet.

**Guerrilla's sun.** The sun is drawn in the sky where Guerrilla puts it at each hour, and with Guerrilla's tone mapping its golden shafts stream past the mountains and buildings round it. `SunShafts=` under `[GuerrillaWorld]` sets how strong the shafts are (1 as in Guerrilla, 0 none), and changes while you play.

**The sky fades into the haze** near the horizon, as Guerrilla's does: the sky dome, the clouds and the far mountains are fogged as Guerrilla fogs them, and the clouds take the sky's light.

**Objects behave as in Guerrilla.** Each building and prop now uses Guerrilla's own settings for it: whether it casts a shadow, shows on the map, smokes when destroyed, stays anchored, and its team and salvage. Before, about 2,000 objects fell back to a default and most others used Armageddon's tuning. Props also switch off at Guerrilla's own distances (25 to 200 m), fading out over half a second instead of popping.

**Building the world takes far less memory**: about 3 GB at most, where it could take 18 GB. The world it builds is the same.

**The developer console shows what you couldn't see before:** the game's own debug output and the error reports it flashes on the screen (marked `[game]`; errors red, warnings yellow), and RFA-Mod's log as it's written. So when something doesn't load or a command fails, the reason is usually right there. `GameLog=` and `ModLog=` under `[Console]` turn them off. It also takes pasted commands (Ctrl+V or Shift+Insert; several lines run one Enter at a time), and Tab completes a command's name and lists the matches with what each one does.

**Fixed:** two crashes in the Guerrilla world: loading a zone a second time, and a crash just after a destroyed prop's effect started.

**Not there yet:** people, vehicles and plants; Guerrilla's missions and story; its far mountains up close; the minimap; effects' sounds, the blowing dust, and the effects placed on their own around the map. The sun casts no shadows yet, so the insides of buildings are lit as brightly as outdoors (the EDF screens glow white there). Glass and effects aren't fogged. Some tall structures can stay hanging in the air while a thin support still holds them.

## Rebuilding the Guerrilla world

Build the world again to get the effects and Guerrilla's object settings:

1. Run `editor\GuerrillaWorld.exe` again (a few minutes).
2. In the game, open the console with the ` key and type `level rfg_12_11` (or any zone's name).

A world built with an older version still opens, as it was.

## Trying the Guerrilla world for the first time

1. You need **Red Faction: Guerrilla Steam Edition** installed (the original, `Red Faction Guerrilla` in your Steam library; Re-MARS-tered's files aren't read yet), and about 1 GB free where RFA-Mod is.
2. In `rfa_mods.ini`, set `GuerrillaDir=` under `[Launcher]` (just below `GameDir=`) to Guerrilla's folder, for example `C:\Program Files (x86)\Steam\steamapps\common\Red Faction Guerrilla`. Both tools read it. (Or give the folder to each tool as its argument.)
3. Run `editor\GuerrillaWorld.exe` (a few minutes).
4. Run `editor\GuerrillaHud.exe` for Guerrilla's HUD (a few seconds). `editor\GuerrillaHud.exe --remove` takes it away again; remove it only that way, since one of its files also holds the pictures of Armageddon's own HUD.
5. Start the game with `RFAModLauncher.exe`, open the developer console with the ` key (from the main menu is fine) and type `level rfg_12_11`.

Run the tools again after updating RFA-Mod. To take the world away, remove the HUD first (`--remove`), then delete `rfg_*`, `zonescript_rfg.vpp_pc`, `rfg.gtodx`, `table.vpp_pc\territories.xtbl`, `effects.vpp_pc\vfx_containers.asm_pc` and `misc.vpp_pc\bitmaps_pc` from `overrides\build\pc\cache\`.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor and its tools: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.4.5-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini`. There are three new settings, which take their defaults if you leave them out: `GameLog=` and `ModLog=` under `[Console]`, and `SunShafts=` under `[GuerrillaWorld]`; the new `rfa_mods.ini` shows them. Then rebuild the Guerrilla world as above.

## Please note

- This is a beta, and the Guerrilla world a work in progress: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, a crash's `logs\crash-*.dmp` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
