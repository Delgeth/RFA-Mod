A beta of RFA-Mod: mods and an editor for the Steam version of Red Faction: Armageddon. Nothing in your game folder is ever changed; the mods work in the game's memory after it starts.

**Download:** `RFA-Mod-v0.4.8-beta.zip` below.

## What's new since v0.4.7-beta

**Dust blows on the wind in the Guerrilla world.** Outdoors, dust and haze stream past you on Guerrilla's wind, with grit in the strongest gusts, and they fade away when you go indoors. `Dust=` under `[GuerrillaWorld]` turns it off (0), and changes while you play.

**Guerrilla's effects look like Guerrilla's.** Smoke, dust and fire are now lit by the time of day the way Guerrilla lights them, so a collapsing building's dust is warm brown instead of pale white. They're also laid over the picture as Guerrilla lays them, so fire, sparks and screens keep their colours instead of burning out white and glowing; `Particles=` under `[GuerrillaWorld]` goes back to Armageddon's way (0). And particles now grow to Guerrilla's sizes: the EDF screens' glow fits their monitors, without the pale square round them.

**The game gets 4 GB of memory instead of 2**, which the Guerrilla world needs. Windows only gives a 32-bit game that much when its program is marked for it, and Armageddon's isn't, so the launcher keeps a copy of the program with that mark in `large_address\` (about 14 MB, made again whenever Steam updates the game) and starts the game from it. Your game folder still isn't touched, and `logs\rfa_mods.log` says how much memory the game got. `LargeAddressAware=0` under `[Launcher]` starts the game's own program.

**Also:** the "Invalid transition navpoint" error at some buildings is gone, the sun no longer leaks under thin overhangs and roof edges, and the renderer's warnings (the box that flashes on screen) are written to the log.

**Not there yet:** people, vehicles and plants; Guerrilla's missions and story; its far mountains up close; the minimap; effects' sounds, the gusts of dust along the ground and the dust devils, and the effects placed on their own around the map. The wind holds at 65 mph, where Guerrilla's wanders between 50 and 80. Glass and effects aren't fogged. Some tall structures can stay hanging in the air while a thin support still holds them.

## The Guerrilla world

**Build your world again** with this version's `editor\GuerrillaWorld.exe`: the dust and the effects' new sizes come from the builder.

## Trying the Guerrilla world for the first time

1. You need **Red Faction: Guerrilla Steam Edition** installed (the original, `Red Faction Guerrilla` in your Steam library; Re-MARS-tered's files aren't read yet), and about 1 GB free where RFA-Mod is.
2. In `rfa_mods.ini`, set `GuerrillaDir=` under `[Launcher]` (just below `GameDir=`) to Guerrilla's folder, for example `C:\Program Files (x86)\Steam\steamapps\common\Red Faction Guerrilla`. Both tools read it. (Or give the folder to each tool as its argument.)
3. Run `editor\GuerrillaWorld.exe` (a few minutes).
4. Run `editor\GuerrillaHud.exe` for Guerrilla's HUD (a few seconds). `editor\GuerrillaHud.exe --remove` takes it away again; remove it only that way, since one of its files also holds the pictures of Armageddon's own HUD.
5. Start the game with `RFAModLauncher.exe`, open the developer console with the ` key (from the main menu is fine) and type `level rfg_12_11`.

Run the tools again after updating RFA-Mod. To take the world away, remove the HUD first (`--remove`), then delete `rfg_*`, `zonescript_rfg.vpp_pc`, `rfg.gtodx`, `table.vpp_pc\territories.xtbl`, `effects.vpp_pc\vfx_containers.asm_pc` and `misc.vpp_pc\bitmaps_pc` from `overrides\build\pc\cache\`.

## You need

- The Steam version of the game on the **publicbeta** branch: in Steam, right-click the game, then Properties → Game Versions & Betas → **publicbeta**. On other builds the game runs normally and the mods leave it alone.
- Windows 10 or 11.
- For the editor and its tools: the 64-bit (x64) [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).

## Installing

Unzip into a folder of your own and set `GameDir=` in `rfa_mods.ini` to your game folder (or start the editor once and pick the folder there). Or unzip it straight into the game folder. Then run `RFAModLauncher.exe` with Steam running. The README has the details.

**Updating from v0.4.7-beta:** copy the new files over your old ones, but keep your own `rfa_mods.ini` and `console.ini`. The launcher adds this version's new settings to them the next time it starts, keeping your values: `LargeAddressAware=` under `[Launcher]`, and `Particles=` and `Dust=` under `[GuerrillaWorld]`. Then build your Guerrilla world again.

## Please note

- This is a beta, and the Guerrilla world a work in progress: expect rough edges, and please report problems as an issue here. `logs\rfa_mods.log`, a crash's `logs\crash-*.dmp` and `version.txt` help.
- For single-player only. Don't use the mods in online multiplayer.
